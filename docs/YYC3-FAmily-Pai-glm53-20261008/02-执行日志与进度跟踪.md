### 2026-10-08 中午 - 5 tag 批量补发 → GitHub >3 tag 哑火

**现象**: 一次 push 5 条 tag（v3.0.0 / v3.0.0-alpha.3 / v1.1.0 / v1.2.0 / v1.0.0），tag 全部上远程但**零 workflow run 被创建**。
**根因**: GitHub 文档化限制——单次 push 超过 3 个 tag 不产生任何 push 事件（防事件风暴）。
**修复**: 分两批（3+2）删除重推，run 全部触发。
**沉淀铁律**: 批量补发 tag 必须 ≤3 条/次。

**验证结果**: 4/5 首跑成功（mcp-servers 3.0.0 / effects 1.1.0 / cli 1.2.0 / theme+ai-hooks 1.0.0），ui 失败 → 修复③

### 2026-10-08 下午 - 修复③ ui 依赖链构建 TS2307（bdb6d1fd）

**根因**: publish 矩阵 job 为全新 runner，只 build ui 自身；ui 经 `workspace:^` 依赖 theme/ai-hooks，其 `dist/` 未构建 → TS2307。Quality Gate 能过是因为 `pnpm -r build` 按拓扑序全量构建。
**修复**: Build 步骤改 `pnpm -r --filter "@yyc3/${{ matrix.package }}..." run build`（连带 workspace 依赖链，全矩阵通用）
**验证**: alpha.3 重发 run ✅，npm beta=3.0.0-alpha.3（npm 侧处理延迟约 10 分钟，非丢包）

### 2026-10-08 下午 - 修复④ ui 出口错位 + alpha.4（216f4863）

**根因**（干净屋实测抓出）: ui 三个新出口 `./hooks` `./theme-manager` `./performance` 在 package.json 声明目录形式（`dist/hooks/index.js`），但 tsup 产物为单文件（`dist/hooks.js`）→ `import('@yyc3/ui/hooks')` ERR_MODULE_NOT_FOUND。
