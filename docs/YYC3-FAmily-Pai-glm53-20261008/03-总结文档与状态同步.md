## 遇到的问题与解决方案

| 问题 | 解决方案 | 经验教训 |
|------|---------|---------|
| GitHub 单次 push >3 tag 静默哑火 | 分批 3+2 删除重推 | **铁律：批量 tag ≤3 条/次** |
| npmmirror tarball 同步滞后（元数据先到） | 实测加 `--registry=https://registry.npmjs.org` | **发布实测必须走官方源** |
| 本机 npm 无凭据 | 借道 GH Actions + 仓库 secret 执行 npm 管理命令 | npm 账号操作可托管给 CI |
| tsup 单文件产物 vs 目录式 exports 声明 | 出口路径对齐产物；干净屋导入实测兜底 | **发布前必须真实安装导入验证** |
