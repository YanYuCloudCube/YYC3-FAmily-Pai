# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-05-08

### Added

- `NeonCard` — 霓虹发光卡，支持 cyberpunk + liquidGlass 双主题
- `GlitchText` — 赛博朋克故障风格文字
- `ParticleCanvas` — Canvas 粒子网络背景
- `CyberpunkWidget` — 赛博朋克悬浮窗，可拖拽/多标签
- `TiltCard` / `FlipCard` / `StackedCards` / `PerspectiveContainer` / `RotatingShowcase` / `FloatingCard` / `GlassRefractionCard` / `BookPage` — 3D 特效组件
- `RippleButton` / `PulseButton` / `MagneticButton` / `AnimatedInput` / `AnimatedSwitch` / `LoadingButton` / `AnimatedCounter` / `AnimatedCheckbox` / `LikeButton` — 微交互组件
- `Parallax` / `ParallaxBackground` / `SmoothParallax` / `ParallaxText` / `ParallaxImage` / `ParallaxStack` / `ParallaxReveal` / `ScrollProgress` / `ScrollTrigger` / `Parallax3DCard` / `InfiniteScroll` — 视差滚动组件
- ESM + DTS 构建 (tsup)
- 完整 TypeScript 类型导出
