# @yyc3/mcp-servers

> MCP 服务器 — 注册表 / 服务端 / 协议实现

## 概览

`@yyc3/mcp-servers` 提供 MCP（Model Context Protocol）服务器实现，包括注册表管理、服务端运行和协议实现。

## 安装

```bash
pnpm add @yyc3/mcp-servers
```

## 核心模块

| 模块 | 说明 |
|------|------|
| **MCPRegistry** | MCP 服务器注册表 |
| **MCPServer** | MCP 服务器运行时 |
| **Protocol** | MCP 协议实现 |
