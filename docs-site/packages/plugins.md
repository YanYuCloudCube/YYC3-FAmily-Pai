# @yyc3/plugins

> 插件集合 — LSP 语言服务器 (4) + 内容处理 (4)

## 概览

`@yyc3/plugins` 提供 8 个插件，涵盖 LSP 语言服务器（TypeScript、Python、Go、Rust）和内容处理（Markdown、代码格式化、Git 增强、文件搜索）。

## 安装

```bash
pnpm add @yyc3/plugins
```

## 插件清单

### LSP 语言服务器

| 插件 | 说明 |
|------|------|
| **TypeScript LSP** | TypeScript / JavaScript 语言服务 |
| **Python LSP** | Python 语言服务 |
| **Go LSP** | Go 语言服务 |
| **Rust LSP** | Rust 语言服务 |

### 内容处理

| 插件 | 说明 |
|------|------|
| **Markdown** | Markdown 增强渲染 |
| **Code Formatter** | 代码格式化 |
| **Git Enhanced** | Git 增强功能 |
| **File Search** | 高级文件搜索 |
